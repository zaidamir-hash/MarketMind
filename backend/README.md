# Backend

This folder contains the FastAPI backend scaffold for MarketMind.

## Current State

- Structure only
- No business endpoints yet
- No ETL jobs yet
- No AI services yet

## Planned Areas

- `app/core/` configuration and security utilities
- `app/db/` database session wiring and model references
- `app/schemas/` Pydantic schemas
- `app/routers/` API routers
- `app/services/` service-layer logic
- `app/etl/` data ingestion modules
- `app/ai/` simple demo-friendly AI modules
- `app/jobs/` scheduled job wiring
