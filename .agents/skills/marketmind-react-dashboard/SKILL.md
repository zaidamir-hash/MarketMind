---
name: marketmind-react-dashboard
description: Use when building the MarketMind React frontend, dashboards, charts, portfolio screens, risk panels, signal leaderboard, alerts UI, or API integration.
---

Use:

- React
- Vite
- JavaScript only
- Recharts
- clean component structure
- frontend API service layer

Recommended pages:

- Dashboard
- Assets
- Asset Detail
- Portfolio
- Trades
- Alerts
- Risk Dashboard
- Signals
- Predictions
- Optimizer

Rules:

- Do not use TypeScript or TSX.
- Do not hardcode fake data once backend endpoints exist.
- Use API services under src/services/api.
- Keep chart components reusable.
- Keep styling consistent and simple.
